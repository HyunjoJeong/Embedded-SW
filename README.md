## Intro

임베디드 SW 실습 코드 관리용 레포

## 실습 환경

| 기간      | MCU        | 제조사    | 개발/업로드 환경                   |
| --------- | ---------- | --------- | ---------------------------------- |
| 1–10주차  | ATtiny4313 | Microchip | `avr-gcc`, `avrdude`, USBasp (ISP) |
| 11–15주차 | STM32F103  | ST Micro  | STM32 개발 도구 및 ST-Link 예정    |

### ATtiny4313 실습 환경

- 내부 RC 오실레이터 (8MHz)
- USBasp를 이용한 ISP 프로그래밍
- 각 프로젝트 폴더의 Makefile 참고
